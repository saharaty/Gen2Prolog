# Public distribution scope

This public distribution contains the frozen Phase 2 screening implementation, campaign inputs, reviewed protocols, evidence, results and reproduction records.

The entire historical Phase 1 directory is withheld, including the Talk2Prolog workbooks, reference translations, prompt templates, notebooks, model-output tables and the nested historical archive. No permission to redistribute the Talk2Prolog material has been established. This is a distribution restriction, not a change to the thesis experiment. The original private files remain preserved. Attribution alone is not permission.

The independent historical Phase 1 experiment cannot be reproduced from this public package. Obtain the original benchmark and any required permission from its rights holder. No replacement benchmark has been invented. Phase 2 screening has no runtime dependency on the withheld directory.

The project's own code has no assigned open-source license. MIT is a recommendation pending the author's ownership confirmation and approval; it has not been applied. Existing third-party license notices remain effective for their respective components.
